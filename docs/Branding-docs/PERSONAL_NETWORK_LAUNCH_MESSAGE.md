> **Paper 1 practice question:** A child believes that a tall glass contains more water than a short, wide glass, even when both contain the same amount. Which concept explains this difficulty: centration, scaffolding, object permanence, or assimilation?
>
> **Answer:** Centration. The child focuses on one visible feature, such as height, instead of understanding that the quantity remains unchanged.
